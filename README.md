# Clipper

Telegram bot for clipping videos

## Requirements

 - ffmpeg

 - python 3.12

 - pipenv

## Usage

1. ```pip install -r requirements.txt```

2. ```python clipper.py```

3. The program will fail due to no API key configured. A config.ini file will be generated, place your API key in there and run again

4. ```python clipper.py```
